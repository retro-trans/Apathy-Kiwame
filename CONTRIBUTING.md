# Contributing

Please report the patch version, scene, choices taken, and a screenshot of the
problem. Avoid uploading game archives, complete executables, save files or
private working scripts. Use a non-graphic description for the adapted Life
passage rather than posting original restricted text or imagery.

English corrections should include the field IDs, nearby context and a brief
reason. Keep approved glossary names, placeholders and fragment structure.
Read [TRANSLATING.md](TRANSLATING.md) before submitting script changes.

The current release is AI-translated and AI-reviewed. Human proofreading and
playtesting are welcome. Please distinguish lines you checked and passed from
lines you rewrote, and state whether you compared them with the Japanese source.

Community: [discord.gg/MssepShjmB](https://discord.gg/MssepShjmB).
