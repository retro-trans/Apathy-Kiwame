# English typography and backlog

The English dialogue, backlog, and horizontal choice controls use the unmodified GenEi LateGo P v2 font, version 2.1, from the [font page requested by the user](https://okoneya.jp/font/genei-latin.html). The official [download page](https://okoneya.jp/font/download.html) supplies `GenEiLatin-Separate_v2.1.zip`. The font and its original SIL Open Font License 1.1 are kept in `tools/fonts/genei-latin`, with copyright and download checksums in `NOTICE.txt`. The installer copies all three files into the local game's `package.nw/fonts` folder. No system font installation is needed.

The existing game already supports proportional text. Native canvas measurements at 22px match the font's advance widths exactly: `i` is 6.57421875px, `W` is 22px, and `.` is 6.810546875px. This verifies the bundled face loaded rather than a fallback.

English script ellipses use ASCII `...`. The exporter and build renderer normalize Unicode ellipses inside translated text while retaining the number of pauses, fields, fragments, and all control tags. The runtime also normalizes dialogue, ending labels, board captions, and custom video caption overlays. This typography pass changes no sentence meaning. Existing photographed lettering and encoded cutscenes retain their separately reviewed Latin typefaces.

The opening and reviewed routes use 22px dialogue with a 27px line height. The opening previously retained the original 38px line spacing, so long pages extended below the message area. Regression checks measure every visited pause against both the text area's bottom and the toolbar's top, and verify the final reply is present. They do not hide or truncate overflow.

Native load restores previously rendered message HTML as well as interpreter state. The English load hook reapplies the layout and normalizes ellipses in restored text nodes, so a slot created before this fix adopts the new spacing immediately. A read-only load of the user's existing slot at opening line 755, followed by 21 measured pauses through the reported hallway page, passed. Both the settings save and slot-data file are preserved byte for byte in the corrected build.

The stock engine's backlog omitted `[r]` breaks while recording adjacent text fragments. The English wrapper records speaker and paragraph breaks through the existing log function without introducing interpreter orders or pauses. The backlog uses zero added letter spacing and has a dark background with light text. Native tests check the previously joined phrase “I could come get you.”, the final hallway reply, scrolling to both ends, and closing the log.

Evidence for the default-name and maximum-name opening replays is under `work/ui/0.1.19-readability-*`; the separate font and scroll check is `work/ui/0.1.19-font-and-scroll.json`. The reported hallway page ends at y=551, inside its y=637 text limit, with default names and with ChristopherX Fitzwilliams.

Since 0.1.20, layout-only breaks within continuous English are spaces instead of forced newlines. The audit in `tools/text_flow.py` examines all 18,604 translated fields in 22 script files. Its map reflows 3,593 breaks in 14 files and preserves 12,610 speaker, paragraph, sentence-end, staging, and other breaks. It handles split hyphens, em dashes, and ellipses without inserting stray spaces. Character names come from the glossary; manual review additionally distinguishes an inline quotation in `game.ks:4326` from quoted speaker labels. No translation wording or scenario file changes are needed.

The runtime still executes every original break command, retaining its delay and one interpreter advance. The native parser and renderer checked all 16,203 audited breaks against the map, including the retained breaks, with matching text and backlog output. The complete audit is `work/ui/english-flow-audit.json`; native evidence is `work/ui/0.1.20-flow-matrix-b.json`.

On loading an older slot, the runtime also reflows existing message HTML when its surrounding English matches an audited continuation. It preserves blank lines and speaker names. The reported passage passed both normal replay and a native snapshot restored from the old hard-break layout. Both runs retain the exact wording and all click pauses, with 437 observed pauses and no clipping; the narrow close-up passed 94 more pauses and native save/load. Screenshots and results are in `work/ui/0.1.20-flow-*` and `work/ui/verified_0.1.20.json`.
